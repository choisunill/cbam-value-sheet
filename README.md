# CBAM Value Sheet

EU CBAM 비용을 계산하고 EU 바이어에게 보낼 제안서(Buyer Value Sheet)를 만드는 웹앱입니다. 대상은 한국산 철강·알루미늄 CN 코드(535개 중 524개 계산 가능)이고, 경쟁국 73개국의 CBAM 비용도 공식 기본값으로 계산합니다. 기본값과 벤치마크는 EU 집행위 공개 Excel(기본값 2026-08-06판, 벤치마크 2026-02-06판)에서 가져왔습니다. 단가는 Eurostat Comext(2025년 독일 수입 평균), 관세율은 EU TARIC(북아일랜드 XI 관세 API로 조회), 한글 품명은 관세청 HSK 자료입니다.

- 계산은 브라우저 안에서만 하고, 입력값을 서버로 보내지 않습니다.
- PC에 설치(PWA)해 오프라인에서도 쓸 수 있습니다.
- 계산은 EU 공식 기본값 기준입니다(IR 2026/1740, IR 2025/2620). 실제 배출값과 한국 탄소가격 공제는 반영하지 않습니다.

2026 상경제 세경지교 「탄소는 못 말려」 팀 프로토타입.
