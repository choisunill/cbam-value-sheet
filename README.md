# CBAM Value Sheet

EU CBAM 비용을 계산하고 EU 바이어에게 보낼 제안서(Buyer Value Sheet)를 만드는 웹앱입니다. 대상 품목은 볼트·나사(CN 7318 15, 스테인리스 제외)입니다.

- 계산은 브라우저 안에서만 하고, 입력값을 서버로 보내지 않습니다.
- PC에 설치(PWA)해 오프라인에서도 쓸 수 있습니다.
- 계산은 EU 공식 기본값 기준입니다(IR 2026/1740, IR 2025/2620). 실제 배출값과 한국 탄소가격 공제는 반영하지 않습니다.

2026 상경제 세경지교 「탄소는 못 말려」 팀 프로토타입.

테스트: `node --test`
